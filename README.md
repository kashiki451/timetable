# 我的课表 · 2026 秋季（Android 竖屏全局版）

这是一个纯前端、可离线使用的大学课程表 PWA。

## 特点
- PC 与 Android 共用同一套“周课表”全局界面。
- Android 竖屏下仍显示周一至周日 × 第1～13节的完整课表，不再切换为单日卡片。
- 手机端课程格会自动压缩字体；点击课程查看完整信息。
- 支持第1～18周切换、本周、上一周、下一周。
- 支持新增、编辑、删除、导入/导出 JSON。
- 支持 Android Chrome PWA 安装。

## GitHub Pages
将全部文件上传到仓库根目录，然后：

`Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)`

发布后访问：

`https://kashiki451.github.io/timetable/`

## Android 安装
优先使用 Android Chrome，并确保访问地址为 HTTPS。

页面上的“安装到手机”按钮在浏览器提供 PWA 安装接口时会直接调用安装；如果浏览器没有提供该接口，会弹出手动安装说明，可从 Chrome `⋮ → 安装应用/添加到主屏幕` 完成安装。

## 课程数据
本版共 15 条记录。`2026118001 思想政治理论课（硕士2）` 因同一课程存在两个连续时间段，拆成两条记录。

对于原始课表中标记“未安排周次”、但备注明确写明 3-13 周的课程，本版按备注中的 3-13 周处理。
